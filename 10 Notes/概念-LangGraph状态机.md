# 概念 · LangGraph 状态机

> 考点：为何用图而不是单次 LLM；State / 条件边；多轮挂起；防死循环。

## 一句话

LLM 只做指定节点的抽取与生成；**流程、护栏、退出条件**写在 Graph 里，用 Checkpoint 做多轮续跑。

## 标准答（可背）

- 导诊约 **17 节点**：决策 → 槽位 → 急诊门禁 → 疾病/症状分流 → 澄清 → 置信度 → 生成 / MCP  
- 槽位由 **slot 状态驱动**追问，避免 LLM 反复问同一问题  
- 澄清节点走 END 挂起，下一轮从 Checkpoint 续跑（0~3 轮触顶 fallback）
