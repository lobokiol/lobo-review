# 概念 · 知识图谱 Neo4j

> 考点：KG 解决什么、怎么调用、怎么打分、和 RAG 如何分工。

## 一句话

结构化推理用 KG（症状→疾病→科室），非结构化指南/FAQ 用 RAG；俗语归一也可以落在图谱映射上。

## 标准答（可背）

- 结构：科室 — 疾病 — 症状；按命中与权重聚合科室分  
- 主诉权重大、次要症状较低、**否定症状过滤不参与检索**  
- 调用链：Agent 节点 → MCP Client → MCP Server → Neo4j / Cypher  
- 冷启动可基于公开图谱（如 CM3KG），线上用院内数据增量校正
