## 一、项目背景

### 1.1 业务现状

某零部件工厂订单**全部来自海外俄罗斯**，需按客户图纸生产。旺季人工审核图纸压力大，审核员工多为 40–50 岁，约 **20% 订单**因图纸审核失误被退货，损失材料、工时及海运成本。

### 1.2 建设目标

客户要求引入 AI 完成图纸审核。落地原则：

- **智能体标注问题**，人工针对标红部分核查并做最终判断
- **人工作为最后防线**，不放行全自动
- 退货率从 **20% 降至 5%**，审核人员旺季从 **20+ 人减至 2 人**

### 1.3 核心经验

落地智能体的关键是**拆解业务**——明确 AI 可自动化的环节与需人工拍板的环节；技术方案相对简单，架构应**清晰可组合**，而非堆砌花哨框架。

## 二、系统架构

### 2.1 总体架构

```
订单/图纸接入 → 解析层 → 智能体核心 → 人工审核台 → 反馈闭环
```

| 层级 | 职责 |
| :--- | :--- |
| **接入层** | 俄罗斯订单参数、PDF/CAD/DWG 图纸、ERP 对接 |
| **解析层** | OCR/视觉提取尺寸公差；订单多语种结构化 |
| **智能体核心** | 规则比对引擎 + LLM 语义补盲 + 标红输出 |
| **人工审核台** | 原图对照、差异高亮、不符合项批注、最终拍板 |
| **反馈闭环** | 人工改判回流、金标迭代、Prompt/规则优化 |

### 2.2 大模型作用定位

| 大模型负责 | 规则/工程负责 |
| :--- | :--- |
| 俄文/英文工艺说明语义理解 | 数值尺寸精确比对 |
| 非标排版、手写批注理解 | 公差计算、单位换算 |
| 标红项中文摘要生成 | 批量吞吐、任务队列 |
| 灰色地带辅助判断（带置信度） | 状态持久化、断点恢复 |
| 客户澄清邮件草稿（可选） | **最终放行/退货（人工）** |

### 2.3 端到端流程

1. 客户下单并提交图纸  
2. 系统解析订单参数（多语种）与图纸要素  
3. 规则引擎逐项比对尺寸、公差、技术要求  
4. LLM 处理语义模糊项，输出标红清单  
5. 审核员只看标红，确认/驳回/发起澄清  
6. 放行生产或退回客户；结果入库用于迭代
