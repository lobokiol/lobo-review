# **rag遇到了什么问题，怎么解决，流程，初始---指标---迭代**

RAG 的整体流程可以概括为：将用户问题先通过知识图谱转为完整的专业句子（用户画像）再转为向量并结合关键词（性别，年龄）进行多路检索，通过粗排，融合，精排筛选出最相关的上下文，打分排名，增加rewrite，分数过8.2，则再将其与问题一同输入大模型生成基于证据的最终答案。

 Recall@50 85% – 95% Precision@3 / Precision@5 ≥ 80% – 95%

**BGE-M3**  **ES + Milvus** **BGE-Reranker-v2** **Qwen-7B**

第一阶段，入库metadate的确定和样本的收集，入库字段太少，导致rag结果差，且卡

- **qa_id**: 唯一标识符（与 Milvus 对应）。
- **question_text**: 原始问题文本（用于关键词匹配）。
- **answer_text**: 原始回答文本。
- **symptom_tags**: 提取出的症状关键词数组（如：["头痛", "发烧", "流鼻涕"]）。
- **version**/**update_time**/**status**: 版本和更新时间/弃用
- **department / gender / age_range**: 冗余存储这些字段，用于 ES 端的聚合分析。

人群错位问题 --- 腹痛，无法区分儿科，妇科，消化内科。

在RAG第二阶段引入结构化约束，将科室、性别与年龄分段等元数据与向量一同存储，并在检索时通过硬过滤仅保留匹配人群特征的候选数据，从源头消除人群错位问题，在适度收缩召回范围的同时将Recall由50%提升至60%、Precision由20%提升至65%，显著提高结果相关性与整体稳定性

第三阶段，无法区分 **甲型肝炎、乙型肝炎** **急性肾衰竭** vs **慢性肾功能不全** **病毒性肺炎** vs **细菌性肺炎** 1型与2型糖尿病，recall由60%-- **90%**

第四阶段，通过交叉编码器对“58岁男性、持续2小时压榨性胸痛且有高血压病史、劳力诱发”的当前患者与Top-50候选问答进行逐对深度比对，并结合发病时长、既往史及人群特征进行加权重排，使原本因表层匹配而排在前列的“肌肉拉伤”等低相关结果被下调，而“急性心肌梗死”“不稳定型心绞痛”等在症状性质、时间维度和诱因上高度一致的结果被提升至Top-3，在不影响Recall约90%的前提下将Precision提升至约90%，从而确保最终输出与当前病例高度一致且具备临床参考价值。

# lora的流程


在面试中，你可以用这一句话展现你的实战深度：

**“在 L40 (48G) 环境下，我基于 Qwen-7B 使用 LoRA (Rank 64, Alpha 128) 对 8000 条四类医疗意图样本进行专项微调，通过『全量基础+难例 (Badcase) 增强』的闭环流程，将路由准确率从 85% 提升至 98% 以上。”**



- **参数 (LoRA Params):**
  
  - Rank=64, Alpha=128：高秩 (Rank) 为了捕捉医疗口语中细微的语义差别。
  - Target Modules: 覆盖 Q, K, V, O 及 MLP 层（全线性层），确保模型深度理解意图边界。
  
- **流程 (Workflow):**
  - **数据构造**（四分类 + 复合意图）→ **QLoRA 微调** → **混淆矩阵分析** → **Badcase 针对性扩充** → **回归测试**。
  
- **样本 (Samples):**
  - **数量**：5000 - 8000 条。
  - **策略**：急诊过采样 + 难例对比（如“心里堵”vs“心口堵”）。
  
- **显卡 (GPU):**
  - **L40 (48G)**：利用其大显存开启大 Batch Size (64+) 训练，并支持 BF16 全程加速，推理延迟控制在 50ms 以内。
  
- **核心价值:**
  - 实现了医疗系统的**安全分流**，是后续 RAG 检索和 Agent 调用的**稳定性基石**。
  
- 困难

  - 口语化描述，无法区分闲聊和导诊，eg: 脑瓜嗡嗡的

  - 多意图融合，而不是单意图,eg: 肚子疼，去哪里挂号

  - 急诊样本太少，隐喻无法识别，eg：我喝了洗洁剂

  - 类别边界接近

  - | 容易混的表达                   | 真正区别                                       |
    | :----------------------------- | :--------------------------------------------- |
    | “心里堵” vs “心口堵”           | 前者可能偏情绪/心理，后者可能偏胸闷/心血管风险 |
    | “头晕” vs “头痛”               | 一个是眩晕/乏力类，一个是疼痛类                |
    | “想吐” vs “吐血”               | 一个是消化道不适，一个是危险信号               |
    | “肚子疼” vs “右下腹持续加重疼” | 后者风险明显更高                               |
