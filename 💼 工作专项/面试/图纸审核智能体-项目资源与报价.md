## 一、项目资源投入明细

| 项目经理 / 需求分析 | 业务调研与流程梳理；方案选型对齐；里程碑与交付管理；验收标准制定与结项验收 | 4.0 | 1.25 | 5.0 |
| **智能体工程师** | Agent 工作流编排、Tool Schema 设计、状态机、失败恢复、Trace/评测流水线、护栏策略 | 5.0 | 2.20 | 11.0 |
| 算法工程师 | 多模态/LLM 本地化部署；Prompt 工程；图纸解析与参数提取算法；标红精度调优与回归评测 | 7.0 | 2.00 | 14.0 |
| 后端工程师 | 系统后台与任务队列；规则引擎；工具 Schema 与 API 集成；状态持久化与断点恢复 | 5.0 | 2.00 | 10.0 |
| 前端 / 交互开发 | 审核操作台；差异标红高亮与原图对照；不符合项清单与批注；审核报表与可视化看板 | 3.0 | 1.33 | 4.0 |
| 数据 / 标注支持 | 历史订单与图纸脱敏清洗；俄文/英文术语库与参数标准库建设；金标样本标注 | 2.5 | 1.20 | 3.0 |
| 测试与实施交付 | 全链路联调与压测；审核员操作培训；试点上线与陪跑；运维手册与交付文档 | 3.0 | 1.00 | 3.0 |
| **合计报价** | 软件开发 + 实施服务费（**硬件、云资源、第三方 API 另计**） | **29.5** | 均价 **1.69** | **50.0** |

> 人月合计 29.5，项目周期约 **10 个月（43 周）**。算法与智能体在阶段一、二并行开发，实际日历工期短于人月累加。

## 二、核心团队成员介绍

| 角色 | 人数 | 能力要求 | 在本项目中的分工 |
| :--- | :---: | :--- | :--- |
| **项目经理** | 1 | 制造业/外贸订单场景经验；具备 AI 项目落地与验收管理能力 | 对接工厂老板与审核班组；拆解「智能体标注 + 人工拍板」边界；把控进度、风险与验收 |
| **智能体负责人** | 1 | Agent 编排、状态机、Tool Schema、可观测性 | 主导审核流水线；设计工具调用链；Trace/评测基建；护栏与失败恢复 |
| **算法负责人** | 1 | 多模态大模型应用、OCR/文档理解、Prompt 与评测体系 | 主导图纸解析与语义比对；设计标红策略；建立精度评测与迭代闭环 |
| **算法工程师** | 1 | 工程图纸要素提取、规则+模型混合方案 | 公差/尺寸提取调优；俄文标注识别；误报漏报分析与 route 优化 |
| **后端负责人** | 1 | 高并发任务调度、规则引擎、可观测性 | 规则比对引擎；API 集成；日志、回放与监控埋点 |
| **前端工程师** | 1 | 复杂表单与图纸对照类交互 | 审核工作台；标红定位与批注；审核员友好型界面 |
| **数据工程师** | 1 | 数据治理、标注规范、术语库建设 | 标准库与金标集；历史退货样本回流；评测集版本管理 |
| **实施工程师** | 1 | 现场培训、灰度上线、问题响应 | 旺季前压测与上线；审核 SOP 编写；试点期驻场支持 |

### 三岗分工对照

| 岗位 | 做什么 | 不做什么 |
| :--- | :--- | :--- |
| **智能体工程师** | 拆步骤、定状态机、设计工具调用链、可观测与评测基建 | 不负责纯数值规则引擎、不负责 UI |
| **算法工程师** | 模型部署、OCR/解析、Prompt、标红精度、金标回归 | 不负责 ERP 对接、不负责审核台 |
| **后端工程师** | 规则比对引擎、API、队列、持久化、权限日志 | 不负责 Prompt 调优、不负责 Agent 编排策略 |

## 四、项目交付边界界定

| 划分 | 具体内容 | 验收物 | 周期 |
| :--- | :--- | :--- | :---: |
| **预研（前置）交付** | 关键解析/翻译可行性报告；准确率口径与金标数据集建设方案；硬件资源评估（2卡/4卡）；准确率指标确认书 | 4 份签字文件 | 2–3 周 |
| **阶段一（订单参数提取）** | 多语种解析、参数提取、结构化 Excel；私有化部署、安全配置、系统联调；阶段培训、测试报告、大模型部署文档；行业术语库与数据集 | 程序包 + 文档 + 测试报告 | 8–10 周 |
| **阶段二（图纸比对）** | DXF/PDF 解析、规则比对、标红、告警、合规报告、权限日志、审核台、ERP 联调 | 完整系统 + 试运行报告 | 12–16 周 |
| **阶段三（迭代优化）** | Prompt 调优、Bug 修复、体验优化、灾备、陪跑、终验 | 终版系统 + 全套验收材料 | 8–12 周 |

### 做 / 不做边界

| 划分 | ✅ 包含 | ❌ 不包含 |
| :--- | :--- | :--- |
| **预研** | 小样本试跑、准确率口径、金标方案、硬件建议 | GPU 采购、正式环境搭建 |
| **阶段一** | 订单解析工具、Excel 结构化、术语库、私有化部署 | 客户历史数据清洗人工成本 |
| **阶段二** | 解析/比对/标红引擎、审核台、约定范围内 ERP 对接 | CAD 源文件格式全覆盖、ERP 二次开发 |
| **阶段三** | 培训、陪跑、文档、首月调优 | 7×24 长期运维（可另签） |

## 五、验收指标

| 指标 | 目标 | 度量方式 |
| :--- | :--- | :--- |
| 字段提取准确率 | ≥ 92% | 金标数据集字段级对比 |
| 标红召回率 | ≥ 90% | 历史退货样本回归集 |
| 标红误报率 | ≤ 15% | 人工改判统计 |
| 单均审核时长 | 较人工全审缩短 ≥ 60% | 系统日志 |
| 系统可用性 | ≥ 99%（工作时间） | 监控平台 |
| 人工最终拍板 | 100% 放行须经人工确认 | 流程审计 |
| 业务效果 | 退货率 ≤ 5% | 客户业务数据 |
